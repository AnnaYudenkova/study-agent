# Учебный помощник

**Учебный помощник** — проект ИИ-агента для студентов, который будет помогать вести список учебных заданий, следить за сроками сдачи и отмечать выполненную работу. Общение с агентом планируется на естественном языке.

## Язык программирования

Для разработки выбран `Python`. Он используется в примерах курса и позволяет последовательно добавлять работу с LLM, инструментами агента и внешними сервисами.

## Планируемые возможности

- **Добавлять задания:** сохранять предмет, описание работы и срок сдачи, присваивать заданию номер и начальный статус «не выполнено».
- **Показывать список заданий:** выводить невыполненные работы по всем предметам или по выбранному предмету, сортируя их по сроку сдачи.
- **Находить ближайшие сроки:** показывать невыполненные задания, которые нужно сдать до указанной пользователем даты включительно.
- **Отмечать выполнение:** менять статус выбранного по номеру задания на «выполнено», сохраняя его в общем списке.
