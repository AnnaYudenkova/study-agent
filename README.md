# Учебный помощник

**Учебный помощник** — проект ИИ-агента для студентов, который будет помогать вести список учебных заданий, следить за сроками сдачи и отмечать выполненную работу. Общение с агентом планируется на естественном языке.

## Язык программирования

Для разработки выбран `Python`. Он используется в примерах курса и позволяет последовательно добавлять работу с LLM, инструментами агента и внешними сервисами.

## Планируемые возможности

- **Добавлять задания:** сохранять предмет, описание работы и срок сдачи, присваивать заданию номер и начальный статус «не выполнено».
- **Показывать список заданий:** выводить невыполненные работы по всем предметам или по выбранному предмету, сортируя их по сроку сдачи.
- **Находить ближайшие сроки:** показывать невыполненные задания, которые нужно сдать до указанной пользователем даты включительно.
- **Отмечать выполнение:** менять статус выбранного по номеру задания на «выполнено», сохраняя его в общем списке.

## Текущий этап

В лабораторной работе № 1 определены назначение проекта, язык и планируемые возможности. Реализация агента, подключение LLM и внешних сервисов предусмотрены на следующих этапах.

## Примеры запросов и ожидаемые результаты

Сценарии описывают планируемое поведение агента. Даты и номера заданий приведены для примера.

### 1. Добавление задания

**Запрос пользователя:**

> Добавь задание по математическому анализу: решить задачи 1–10. Срок сдачи — 30 октября 2026 года, 18:00.

**Ожидаемый результат:** агент создаст задание и подтвердит сохранённые данные:

- номер: `1`;
- предмет: математический анализ;
- описание: решить задачи 1–10;
- срок сдачи: 30.10.2026, 18:00;
- статус: не выполнено.

### 2. Просмотр заданий с ближайшими сроками

**Исходные данные:** в списке есть невыполненное задание № 1 из первого сценария, невыполненная лабораторная по программированию со сроком 3 ноября 2026 года и уже выполненный доклад по истории со сроком 29 октября 2026 года.

**Запрос пользователя:**

> Покажи невыполненные задания, которые нужно сдать до 31 октября 2026 года включительно.

**Ожидаемый результат:** агент покажет только задание № 1:

| Номер | Предмет | Задание | Срок сдачи | Статус |
| --- | --- | --- | --- | --- |
| 1 | Математический анализ | Решить задачи 1–10 | 30.10.2026, 18:00 | Не выполнено |

Лабораторная по программированию не попадёт в результат, потому что её срок позже указанной даты. Доклад по истории не попадёт в результат, потому что уже выполнен.
